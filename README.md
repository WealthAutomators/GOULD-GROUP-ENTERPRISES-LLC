# GOULD GROUP ENTERPRISES LLC

Bold contemporary American marketplace storefront.

**Tagline:** More Choice. More Value. Made For Everyday.

**Contact**
- Email: gouldgroupenterprisesllc@gmail.com
- Address: 17350 STATE HWY 249, STE 220, HOUSTON, TX 77064

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui + Radix UI
- Framer Motion + Embla Carousel
